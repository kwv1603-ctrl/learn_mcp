## 一、近期重大公司事件

### 1.1 史上最大规模股权融资 — 800亿美元（后上调至847.5亿美元）

**日期**: 2026年6月1日（公告）/ 6月3日（上调定价）

**事件概要**:
Alphabet宣布启动公司史上最大规模股权融资计划，原定800亿美元，后于6月3日宣布上调至约847.5亿美元。融资结构包括三部分：

| 融资方式 | 金额 | 详情 |
|----------|------|------|
| 同步承销公开发行 | ~300亿美元 | 含150亿强制可转换优先股 + 150亿A/C类普通股 |
| 市价发行 (ATM) | ~400亿美元 | 2026年Q3启动，分阶段发售 |
| 伯克希尔·哈撒韦私募 | 100亿美元 | 每股$351.81认购A类、$348.20认购C类 |

**关键信号**:
- 巴菲特背书：伯克希尔自2025年Q3首次建仓（43亿美元），2026年Q1加仓至156亿美元（第七大持仓），此次再投100亿美元
- 资金用途：扩建顶级AI算力基础设施，满足"空前高涨的市场需求"
- 公司表述："AI正推动公司进入扩张周期，需求已超出现有供给能力"
- 市场反应：盘后一度下跌约2%（股权稀释担忧），随后收复至约-1%

**影响评估**: ✅ **正面偏中性** — 巴菲特背书是强烈信心信号，但大规模稀释对短期股价构成压力；融资说明管理层判断AI投资回报期较长，资本开支将持续多年高企。

### 1.2 Waymo推出30美元月费会员计划

**日期**: 2026年6月12日（今日）

**事件概要**:
Alphabet旗下自动驾驶公司Waymo宣布推出"Waymo Premier"会员计划，月费30美元，权益包括：
- 优先接送服务
- 每次行程10%乘车返现（积分形式）
- 新城市优先体验Waymo服务
- 每月最多5次免费取消行程

初期仅限受邀用户，覆盖旧金山、洛杉矶、凤凰城，计划后续推广至其他城市。此前Waymo每周全自动驾驶出行已突破50万次，并已推出第六代Robotaxi系统。

**影响评估**: ✅ **正面** — Waymo商业化进一步深化，会员制意味着从按次付费走向订阅经济模式，提高用户粘性和收入可预测性。虽然Other Bets目前仍亏损（Q1亏损21亿美元），但商业模型日趋清晰。

### 1.3 Google I/O 2026 — Gemini 3.5 & 全栈Agentic AI发布

**日期**: 2026年5月19日

**战略意义**: Google I/O 2026标志着从"AI工具"向"AI Agent"的战略转型。搜索从"链接分发"进化为"意图捕获+交易闭环"，商业模型从广告扩展至订阅+交易佣金。

**影响评估**: ✅ **强烈正面** — I/O 2026展示了谷歌在AI时代的完整战略图和执行力，$100/月Ultra订阅打开了新的ARPU天花板。

## 二、DOJ反垄断诉讼进展

### 2.1 时间线回顾

| 时间 | 事件 |
|------|------|
| 2024年8月 | 法官Mehta裁定谷歌在搜索市场非法垄断 |
| 2024年11月 | 司法部提议强制剥离Chrome浏览器 |
| 2025年4-5月 | 补救措施听证会（三周），谷歌以"国家安全/对华竞争"抗辩 |
| 2025年9月2日 | **法官Mehta发布补救裁决**：采用行为性补救，**拒绝拆分Chrome** |
| 2026年1月 | 谷歌提起上诉（挑战数据共享和技术委员会监督条款） |
| 2026年2月 | DOJ与多州提起交叉上诉（寻求更强硬补救：Chrome剥离、终止苹果默认搜索协议） |
| 2026年4月 | 谷歌申请紧急暂停数据共享令（以"不可逆损害"为由），Mehta尚未裁决 |

### 2.2 当前补救措施内容

| 措施 | 详情 |
|------|------|
| 排他性协议禁令 | 6年内禁止与设备商签订排他性搜索/Chrome/Gemini默认协议 |
| 搜索数据共享 | 须向合格竞争对手共享搜索索引和用户交互数据（不含广告数据） |
| 搜索联合服务 | 须向竞争对手提供搜索和搜索文字广告联合服务 |
| 广告拍卖透明 | 公开披露广告拍卖机制变更 |
| 技术委员会 | 5人委员会监督合规执行 |
| 年度重新竞价 | 默认搜索合同须每年重新竞价 |
| GenAI覆盖 | 补救措施明确延伸至生成式AI产品 |

### 2.3 判决评估

**关键利好**：Chrome未被拆分！法官Mehta明确拒绝了DOJ最激进的拆分要求，认为Chrome和Android"并非谷歌非法限制竞争的工具"，强制拆分属于"监管越权"。

**核心风险**：
- DOJ交叉上诉仍在推进，寻求更高层级法院推翻Mehta裁决
- 2027年中D.C.巡回上诉法院将审理，2028年可能到达最高法院
- 数据共享条款对谷歌竞争优势构成实质威胁

**历史参照**：D.C.巡回上诉法院曾在2001年推翻微软拆分令。当前裁决同样出自该法院辖区，上诉前景对谷歌相对有利。

**影响评估**: ➖ **中性偏正面** — 最坏情景（Chrome拆分）已被Mehta拒绝；行为性补救的执行影响可控；但DOJ交叉上诉带来长期不确定性。市场已将此风险大部分定价。

## 四、行业政策与监管

### 4.1 反垄断环境

- **搜索案**：如上所述，行为性补救中，DOJ交叉上诉进行中
- **广告技术案**：2025年4月法官Brinkema裁定谷歌垄断广告交易平台和广告服务器市场，补救听证会待定；DOJ要求剥离AdX和DFP平台
- **Play商店案**：2023年陪审团裁定非法垄断，谷歌正与法官命令抗争

### 4.2 全球数字监管

- **欧盟DMA**：谷歌已在欧盟遵守《数字市场法》要求，包括选择屏幕
- **AI监管**：美国尚未通过全面AI立法，各州层面监管碎片化
- **关税影响**：特朗普政府关税政策对科技硬件供应链有阶段性扰动

### 4.3 行业竞争格局

- **搜索**：ChatGPT Search、Perplexity AI等新进入者，但谷歌份额仍约90%
- **云计算**：Azure和AWS保持领先，但谷歌Cloud增速(63%)远超竞争对手
- **AI模型**：OpenAI、Anthropic（谷歌本身就是Anthropic投资者）、Meta Llama竞争激烈

**影响评估**: ❌ **偏负面** — 三线反垄断诉讼构成持续压力，但核心搜索案最坏情景已被避免。
