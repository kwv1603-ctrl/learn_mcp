# AI对话Follow-up推荐机制调研

> 调研时间：2026年7月24日 | 对象：ChatGPT、豆包、米家/小爱同学

## 一、背景

主流AI产品在回答完用户问题后，会在消息下方展示几个相关推荐按钮（Follow-up Chips），引导用户继续使用。安防类App拥有多种设备能力（实时监控、录像回放、AI检测、双向对讲等），用户问完一个问题后往往不知道还能做什么。参考行业做法，在回答后推荐相关能力，能有效降低使用门槛，提升功能触达。

本次调研聚焦回答完成后的「推荐按钮」设计，不涉及对话过程中的主动追问。

## 二、三款产品的做法

### 2.1 ChatGPT

ChatGPT回答完后，在消息下方展示2~4个可点击的Follow-up建议。

- **展示形式**：圆角按钮（Chip），纵向排列在回答正下方
- **生成逻辑**：基于当前对话上下文，由模型动态生成
- **内容风格**：以用户口吻写成完整问句，如「那如果换成XX方案会怎样？」而非功能名罗列
- **交互**：点击即发送，也可忽略自由输入

### 2.2 豆包

豆包在长篇回答的末尾会展示「你可能还想问」的建议。

- **展示形式**：文本列表形式，通常是2~3条
- **生成逻辑**：基于上下文，提问越具体推荐越精准
- **内容风格**：紧贴回答内容，如「能举个具体例子吗？」「把这个做成表格」等
- **特点**：推荐偏向「怎么深挖当前话题」，而非跳到不相关话题

### 2.3 米家/小爱同学

小爱同学目前在语音交互中以「连续对话」为主，不做Chip按钮。但在有屏设备（智能屏、电视）上，回答后开始出现能力引导卡片。

- **展示形式**：语音建议 + UI快捷卡片（有屏场景）
- **生成逻辑**：结合时间、场景和设备状态主动推荐
- **内容风格**：操作导向，如「需要帮你打开窗帘吗？」「要不要设置个闹钟？」
- **特点**：强调「主动推荐」而非被动等待用户开口

#### 推荐能力的底层实现

与ChatGPT在主模型回答时一次性附带生成Follow-up不同，小爱同学的推荐能力由独立的**多Agent协同架构**驱动，而非大模型单次推理产出。根据小米小爱团队公开的技术分享：

- **10个垂直Agent**：工具Agent、控制Agent、内容Agent、智能家居Agent等，各自负责一个领域的能力执行
- **一个中控Agent**：作为调度中心，知晓每个Agent擅长的能力，负责任务分发和跨Agent流程串联
- **主动推荐决策链路**：综合当前场景（时间/位置）、设备状态变化（洗衣完成/入睡检测）、用户历史操作习惯、设备联动规则等多个信号，由推荐链路独立产出建议

典型流程：设备事件触发（如洗衣完成）→ 规则+模型判断 → 生成推荐卡片（「需要帮你降晾衣架吗？」），而非LLM在回答时顺带生成。

**与ChatGPT的对比：**

| | ChatGPT Follow-up | 小爱主动智能推荐 |
|---|---|---|
| **生成方式** | 主模型一次推理附带生成 | 独立推荐决策链路 |
| **触发时机** | 每次回答后 | 事件驱动（时间/设备状态/场景变化） |
| **依赖数据** | 仅对话上下文 | 对话 + 设备状态 + 用户习惯 + 场景 |
| **架构** | 单一模型 | 多Agent协同 |

## 三、共性设计原则

| 原则 | 说明 |
|------|------|
| **2~4个选项** | 太多会导致选择困难，太少缺乏引导价值 |
| **上下文关联** | 紧扣刚刚聊的内容，别推荐无关功能 |
| **用户口吻** | 用完整操作语句，不要罗列功能名称 |
| **轻量不打扰** | 可点可忽略，不中断正常的自由输入 |
| **方向多样** | 3个建议最好覆盖不同方向：深入当下话题 / 换个相关角度 / 触发一个新操作 |

## 四、安防App应用建议

### 4.1 核心思路

将安防App的能力（实时画面、录像回放、AI检测、告警、对讲、日报等）作为推荐池。用户问完问题后，基于对话内容，推荐3个最相关的能力操作。

**举例：**

用户问「门口刚才有人吗？」→ 回答完 → 推荐：
- 「看看门口实时画面」（核心相关）
- 「有人经过时自动提醒我」（关联扩展）
- 「今天有哪些人出入？」（下一步引导）

### 4.2 推荐生成方式

采用「意图归类 + 能力映射」的方式：

| 用户问题属于 | 推荐能力方向 |
|-------------|-------------|
| 询问实时画面 | 查看画面 → 调整检测区域 → 设置告警 |
| 查询历史录像 | 回放检索 → 截图保存 → 生成出入报告 |
| 关注告警通知 | 检查规则 → 调整免打扰 → 测试推送 |
| 关心设备状态 | 查看存储 → 清理录像 → 健康诊断 |

### 4.3 呈现形式

回答消息下方以3个圆角按钮纵向排列，附带简单图标。用户点击后填入输入框，可二次编辑再发送。

核心一句话：**回答完一件事，顺手告诉用户接下来还能用App做什么。**

## 五、总结

- ChatGPT和豆包已经验证了Follow-up推荐对提升对话深度和功能触达有明显效果
- 安防App天然适合这个模式：用户的问题往往意味着对某类能力的需要，回答完顺势推荐同类或关联能力即可
- 关键约束：控制在3个以内、必须和当次对话相关、用操作语句表达而非功能罗列
